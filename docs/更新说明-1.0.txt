Aside 图标设置 · 1.0.7

1. 明确的保存按钮
   点图标只是"选中"，被改动的网站会用橙色标出，并显示"将从 X 改为 Y"。
   页面底部一直有一条保存栏：有改动时显示"有 N 项更改未保存"和【保存并应用】【放弃更改】；没有改动时显示"所有更改已保存"。
   支持 ⌘S 保存。带着未保存的改动离开页面时，浏览器会提醒。

2. 只有一个设置页
   点扩展菜单或工具栏里的「Aside 图标设置」会直接打开设置页（如果已经开着，就切换过去），不再有单独的弹窗设置。
   原弹窗里的功能都移到了设置页顶部：图标替换开关、"重新应用到已打开的网页"、已打开网页的状态列表。

3. 图标大小
   新增"标准 / 大 / 特大"三档，默认是"大"。
   - 标准：和 0.9.0 一样，图标四周留白较多（图案约占 62%）。
   - 大：去掉四周的透明留白，图标铺满整个格子（约占 96%，看起来大约 1.27 倍）。
   - 特大：在"大"的基础上再把中心放大 1.2 倍，圆角会重新裁好；比较宽的标志（比如哔哩哔哩的 Mac 版）边缘会被裁掉一点。
   只作用于 iPhone、Mac、优化版；原版仍然用网站自己的图标，不做缩放。
   设置页有模拟 Aside 固定区的预览，切换档位时能立即看到效果。
   缩放在本机完成，只处理扩展自带的图标文件，不读取网站图片，也不联网。

安装：已同步到 ~/Library/Application Support/AsidePinnedIcons。需要在 Aside 的扩展管理页里点一下这个扩展的"重新加载"，扩展名称和版本号才会更新。
备份：work/backups/installed-pre-1.0.0、work/backups/pre-1.0.0-extension
测试：variants / variant-ui / content / library 四组测试通过（新增：只点选不保存、批量保存、保存失败时保留改动、放弃改动、图标大小持久化、拒绝来自旧弹窗页面的请求）。

1.0.2：如果 Aside 还在运行旧版本的扩展后台，设置页会提示并提供「立即更新」按钮，点一下即可重启扩展并自动回到设置页。
1.0.3：检测到旧后台时会自动重启扩展一次（2 分钟内不重复），设置页自动重新打开；若仍是旧版本，再显示「立即更新」按钮。
1.0.4：点扩展菜单时先检查后台版本，旧版本会直接重启扩展（同时关掉旧的设置页）；已打开的设置页会被刷新，避免继续使用旧页面。
1.0.5：图标文件本身已裁掉四周留白（原先只占 63%–72%），直接铺满图标位，和网站原图一样大，不依赖扩展后台版本；去掉「标准」档，保留「大」（默认）和「特大」。未裁剪的原图备份在 work/icon-library/untrimmed。
1.0.6：保存时自动全量刷新（清除图片缓存、重画所有打开的网页、短暂唤醒休眠中的固定页再让它休眠）；设置页按钮改为「一键刷新图标」；设置页会对比磁盘上与正在运行的版本，不一致时自动重启扩展。
1.0.7：撤回 1.0.6 的“唤醒休眠固定页”——唤醒后 Aside 先缓存了网站原图，反而让 X 等图标变回原版。刷新只处理已加载的网页，并在提示里列出未加载的固定页（点开一次即更新）。
