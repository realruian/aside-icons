# Aside 图标扩展 · 整体规划

更新：2026-11-15，当前版本 1.1.0

## 现状

**能用的部分**
- 155 个网站，每个网站可选原版、iPhone、Mac、优化版。
- 一个设置页，带明确的保存按钮。保存后会刷新已打开的网页。
- 图标铺满图标位，和网站原图一样大。可选“大”或“特大”。
- 扩展更新后会自动重启后台，不会再出现“改了没反应”。
- 优化版共 84 个：原来 8 个，今天新做 76 个。

**之前方案（Codex）留下的问题**

| 问题 | 后果 |
|---|---|
| 图标文件四周留白 30% 以上 | 固定区的图标比网站原图小一圈（1.0.5 已修） |
| 后台更新后不会自动重启 | 用户改了设置却没反应（1.0.3–1.0.6 已修） |
| 没有 git，所有版本都靠 zip 加备份文件夹 | `outputs/` 里有 52 个文件、13 个 zip，很难找到哪个是当前版本 |
| 网站清单分散在 8 个 `catalog-*.json` 加 5 个构建脚本里 | 加一个网站要改好几处 |
| 有 2 个测试长期失败，一直没人处理 | 测试失去参考价值 |
| 优化版只做了 8 个样例 | 大多数网站没有统一风格可选 |

## 第一阶段：整理工程（建议马上做，约半天）

1. 初始化 git，按下面的结构重新组织：
   - `src/`：扩展源码
   - `assets/`：图标源文件和 SVG
   - `scripts/`：构建、安装
   - `tests/`
   - `dist/`：打包产物
2. 只保留一个网站清单 `catalog.json`。`library.js` 从它自动生成，不再手改。
3. 一条命令完成构建、测试、版本号加一、同步到 Aside 安装目录、打 zip。
4. 删掉两个早已过时的测试（background、geometry）。旧的 zip 和截图归档到 `archive/`。

## 第二阶段：设置页体验（约 1–2 天）

1. **“已固定的网站”置顶**：读取当前固定的标签，把它们排在最前面。你最常改的就是这几个。
2. **批量操作**：一键把所有网站换成优化版、iPhone 版、Mac 版或原版。
3. **真实预览**：预览区显示你实际的固定项和它们的实际选择，不再固定显示 8 个示例。
4. **自定义图标**：给任意网站上传自己的 PNG 或 SVG，自动裁成同样的圆角方块。
5. **自定义网站**：清单里没有的网站可以手动添加，填域名，再选图标或上传。

## 第三阶段：补齐优化版（剩 71 个）

**有现成矢量、可以直接做的**（约 30 个）：
Google Docs、Sheets、Slides，Airtable、Evernote、Todoist、ClickUp、Asana，Firebase、Azure、Google Cloud、AWS、DigitalOcean、Bitbucket、Railway、Render、CodePen、Replit，ElevenLabs、Replicate、Stability、Windsurf、Dify、Civitai，eBay、Booking、Tripadvisor、Epic Games、Quora、IMDb、Wix、WordPress、Sketch、Pexels。

**需要手工绘制或取官方素材的**（国内为主）：
飞书、钉钉、腾讯文档、金山文档、WPS、剪映、CapCut、Canva 可画、豆瓣、Vidu、Tripo、Meshy、Cherry Studio、LM Studio、ComfyUI。

## 第四阶段：稳定性

1. **单页应用地址变化**：Gmail 这类网站的地址经常变，扩展会误以为页面换了而跳过处理。需要改成按域名匹配，而不是要求地址完全一致。
2. **网站自己改图标**：比如未读数角标。目前会重新替换，但可能闪一下。可以加防抖，或者提供“保留角标”的选项。
3. **未加载的固定项**：Aside 关闭后的固定项不在标签列表里，扩展看不到，只能点开一次才更新。这一条无法彻底解决，只能在设置页里提示。
4. **设置同步**：把每个网站的选择存到 `chrome.storage.sync`，多台电脑共用同一套设置。
5. **导出和导入设置**：生成一个 JSON 文件，方便备份和换电脑。

## 建议顺序

第一阶段 → 第二阶段第 1、2、3 项 → 第三阶段“直接可做”的部分 → 第四阶段第 1、4 项 → 其余。
